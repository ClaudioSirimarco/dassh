Plataforma web

A mesma interface do aplicativo, no navegador. Ainda é uma proposta: não há login, contas nem dados nesta página.

O que se pretende

  • Consultar histórico, evidências, relatórios e Skills pelo navegador.
  • Dados guardados cifrados no cliente, para que o servidor não leia o conteúdo.
  • Login sem senha (passkeys), com perfis de acesso para equipe e clientes.
  • Funções que dependem da máquina (PowerShell, SSH, serial) por meio do agente local.
Limites previstos. O navegador tem limitações (ex.: porta serial só em Chrome e Edge), então algumas partes seriam equivalentes, não idênticas, ao aplicativo. O app para Windows continua sendo o caminho de máxima fidelidade.

Enquanto isso: baixe o aplicativo ou assista a uma sessão ao vivo com um código de convite.
