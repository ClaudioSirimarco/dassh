Política de privacidade

Em linguagem simples. Última atualização do rascunho: 18/11/2026.

1. Quem somos

O DASSH Console é desenvolvido pela DASSH IT Services. Dados cadastrais completos do controlador (razão social, CNPJ, encarregado de dados): a confirmar.

2. Onde ficam os seus dados

O aplicativo roda no computador do técnico. Logs, evidências, relatórios, gravações e histórico ficam nesse computador, e as senhas do cofre ficam cifradas e protegidas pelo Windows. A DASSH IT Services não recebe esses arquivos pelo aplicativo atual.

3. Compartilhamento ao vivo

O conteúdo da sessão compartilhada é cifrado de ponta a ponta (AES-256-GCM + X25519): a chave fica com os participantes. O código do convite vai no trecho depois do # do endereço, que o navegador não envia ao servidor da página. Para o trânsito das mensagens, o aplicativo atual usa um serviço de mensageria público de terceiros (broker MQTT), que enxerga apenas dados cifrados e metadados de conexão (ex.: endereço IP, horário, tamanho das mensagens). Os termos desse serviço são do próprio provedor.

4. O que o site coleta

  • Este site é estático, hospedado no GitHub Pages. Não usamos cookies de rastreamento nem ferramentas de análise próprias.
  • A página inicial consulta a API pública do GitHub para mostrar o total de downloads; o GitHub pode registrar o seu IP conforme a política dele.
  • Os downloads são servidos pelo GitHub (Releases).

5. Dados de terceiros nos atendimentos

Ao atender um cliente, o técnico pode registrar telas e comandos que contenham dados pessoais ou sigilosos do cliente. Quem usa o aplicativo é responsável por ter base legal e autorização do cliente para isso e por guardar e descartar os arquivos adequadamente.

6. WhatsApp

O recurso de envio usa a automação do WhatsApp Web do próprio usuário, sujeita aos termos do WhatsApp. O que é enviado, e para quem, é decisão do usuário.

7. Seus direitos (LGPD)

Você pode pedir confirmação de tratamento, acesso, correção, eliminação e demais direitos da Lei 13.709/2018. Canal de contato e encarregado: a confirmar.

8. Plataforma web futura

Se a plataforma web em proposta for lançada (veja /app/), esta política será revista antes, para descrever contas, armazenamento cifrado e retenção.
