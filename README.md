# DASSH Code — download

Shell avançado multiprotocolo (Serial, SSH, PowerShell, CMD, Azure, GCP e Web/iDRAC) com cofre de credenciais,
sessão compartilhada com criptografia de ponta a ponta, automação por roteiros e evidências auditáveis com relatório PDF assinado. **DASSH IT Services.**

**➡ Página de instalação (passo a passo): https://claudiosirimarco.github.io/dassh/**

## ⬇ Baixar (Windows 10/11, 64 bits)

**[Baixar o instalador mais recente](https://github.com/ClaudioSirimarco/dassh-code-download/releases/latest)**

- `DASSH-Code-Setup-x.y.z.exe`: instalador. É o recomendado e não precisa ser administrador.
- `DASSH-Code-Portatil-x.y.z.zip`: versão portátil, para rodar de uma pasta ou pendrive.

## Recebeu um convite para uma sessão ao vivo?

1. Instale e abra o DASSH Code.
2. Clique em **🔗 Entrar**.
3. Digite o código que veio no convite (ex.: `ABCD-EFGH-JKLM`).

Você entra como **observador**. Quem convidou aprova a sua entrada e decide quem digita no terminal.
A conexão é criptografada de ponta a ponta.

> **Aviso do Windows:** enquanto o instalador não tiver assinatura digital, o Windows pode mostrar
> "O Windows protegeu o computador". Nesse caso, clique em **Mais informações → Executar assim mesmo**.
