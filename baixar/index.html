Baixar o DASSH Console

Para Windows 10 e 11 (64 bits). Os arquivos ficam nas Releases do GitHub, sempre na versão mais recente.

⬇ Ver a versão mais recente Instalador direto (.exe) Versão portátil (.zip)
Aviso honesto sobre a assinatura digital. A versão atual ainda não tem assinatura digital do instalador. Por isso o Windows pode exibir “O Windows protegeu o computador” (SmartScreen). Isso não significa, por si só, que o arquivo seja malicioso, mas também não é uma garantia da nossa parte: baixe somente por esta página ou pelas Releases oficiais. A assinatura está nos planos, sem data confirmada.

Requisitos

  • Windows 10 ou 11, 64 bits.
  • Não é preciso ser administrador para instalar (instalação só para o seu usuário).
  • Algumas ações pontuais pedem permissão do Windows e avisam antes (ex.: driver do cabo console, IP temporário).
  • Para o cabo console USB-serial, o driver do adaptador pode ser necessário (o app tem um diagnóstico para isso).
  • Espaço em disco e memória mínimos: a confirmar.

Passo a passo

  1. Baixe o instalador (DASSH-Console-Setup.exe) pelos botões acima.
  2. Execute o arquivo. Se aparecer “O Windows protegeu o computador”, clique em Mais informações e depois em Executar assim mesmo.
  3. Abra o atalho “DASSH Console” na Área de Trabalho e escolha uma conexão.

Instalador ou portátil?

Instalador

Cria atalhos e o desinstalador. Recomendado para o uso diário.

Portátil

Descompacte numa pasta ou pendrive e abra DASSH Console.exe, sem instalar.

Desinstalar

Configurações do Windows → Aplicativos → DASSH Console → Desinstalar. Na versão portátil, basta apagar a pasta.
