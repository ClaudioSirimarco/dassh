Agente local

O próprio DASSH Console, rodando em segundo plano só no seu computador, para a interface web usar o que o navegador não alcança.

O que é

Um navegador sozinho não abre porta serial, SSH ou PowerShell. O agente local é o mesmo DASSH Console do Windows, iniciado em modo de segundo plano (sem a janela principal). Ele escuta apenas em 127.0.0.1 (o próprio computador, sem abrir portas na rede) e a interface web conversa com ele. O pareamento entre o navegador e o agente é feito por código.

Como iniciar

  1. Instale o DASSH Console pela página de download (versão 1.0.5 ou mais nova).
  2. Inicie o agente de um destes jeitos:
    • pelo atalho “DASSH Console (agente)” no Menu Iniciar; ou
    • executando DASSH Console.exe --agente.
  3. Abra a interface web e informe o código de pareamento do agente quando ela pedir.

Para que serve

A interface web usa o agente para o que depende do seu computador: serial (portas COM), SSH, PowerShell e CMD, CLIs de nuvem, assistentes de IA de linha de comando, WhatsApp e as demais funções do aplicativo. Sem o agente em execução, a interface web não consegue acessar essas funções.

Limites

  • Chrome, Edge e Firefox funcionam. O Safari pode bloquear a conexão com o computador local.
  • A aba Web (iDRAC, iLO, iBMC, firewalls…) abre o navegador do agente em janela separada, não embutida na página.
  • O agente roda no Windows, no mesmo computador em que você usa o navegador. Ele não atende outros computadores.

Privacidade e segurança

  • Nada sai do computador por causa do agente: a conversa entre a página e o agente acontece dentro da sua máquina, em 127.0.0.1.
  • O agente só aceita a origem do site oficial e exige o código de pareamento; sem ele, a conexão é recusada.
  • Não há portas abertas na rede. Para encerrar o agente, feche o processo do DASSH Console.
Aviso honesto. O agente é o mesmo programa do aplicativo, e a interface web é a mesma do aplicativo. Algumas coisas continuam exclusivas do aplicativo no Windows (veja a documentação). Para trabalhar sem depender do navegador, use o aplicativo na página de download.
