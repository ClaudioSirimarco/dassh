Documentação

Guias curtos para começar. Os detalhes de cada tela estão dentro do próprio app.

1. Instalar

Baixe o instalador na página de download, execute e, se o Windows avisar, use Mais informações → Executar assim mesmo (a versão atual ainda não tem assinatura digital). Não precisa ser administrador.

2. Seletor de conexão novo

No topo do app, clique no botão do tipo de conexão (ex.: 🔌 Serial ▾). Abre um painel com quatro grupos:

  • Equipamentos (precisam de destino): Serial (porta COM do cabo console), SSH (usuario@ip) e Web (iDRAC, iLO, iBMC, firewalls).
  • Shell (abre na hora): PowerShell e CMD.
  • Nuvem: Azure CLI, Google Cloud (gcloud) e AWS CLI. Se faltar a ferramenta, o app instala na primeira vez.
  • IA: Claude Code, Codex, Gemini CLI e Copilot CLI (veja a seção 3).
  1. Escolha o tipo. Para equipamentos, informe o destino (porta COM, endereço ou URL) e clique em Conectar. Shell, Nuvem e IA abrem direto.
  2. As senhas podem ficar no cofre de credenciais, protegido pelo Windows. Quando o equipamento pede login, o app sugere a credencial.
  3. Até 8 sessões ficam abertas em abas. O botão do meio do mouse fecha uma aba.
  4. Cabo console sem resposta? Use o 🩺 ao lado da porta COM (diagnóstico de cabo e driver) e o 🔓 para liberar uma porta presa.

3. Abas de IA novo

No grupo IA do seletor, escolha Claude Code (Anthropic), Codex (OpenAI), Gemini CLI (Google) ou Copilot CLI (GitHub). A ferramenta oficial abre numa aba própria, ao lado da sessão do equipamento.

  • Cada ferramenta pede o login da sua conta com o fornecedor e segue os termos e preços dele. O DASSH não revende nem inclui esse acesso.
  • O que você digita ou cola nessas abas vai para o fornecedor da IA. Não cole senhas nem dados sensíveis de cliente.
  • As abas são separadas: a IA não digita no switch por você. Revise qualquer comando sugerido antes de executar.

4. Aba Web e captura de página inteira novo

  1. No seletor, escolha Web, digite o endereço da iDRAC, do iLO ou do firewall e clique em Conectar. A página abre dentro do app. Certificados próprios desses equipamentos são aceitos.
  2. Janelas que o equipamento abre (ex.: console virtual) viram subabas dentro da mesma aba.
  3. Na barra da aba Web, escolha o modo da evidência: Tela (só o que está visível, padrão) ou Página inteira (inclusive o que está abaixo da dobra).
  4. Gere a evidência com Ctrl+Alt+E ou pelos botões. Uma página comprida é dividida em partes legíveis, cada uma com o seu número.

5. Skills: escolher os comandos novo

  1. Conecte no equipamento e clique em ⚡ Skills (cartão Evidência).
  2. Busque pelo nome ou filtre por fabricante. As Skills do mesmo tipo da aba aparecem primeiro, com a etiqueta “combina com esta aba”.
  3. Ao escolher uma Skill, todos os comandos vêm marcados. Desmarque o que não quiser, ou use Marcar todos / Desmarcar todos. O contador mostra quantos serão executados.
  4. Se quiser, marque Enviar cada evidência no WhatsApp. Clique em ▶ Executar: o app pagina até o fim e salva uma evidência por comando.

Há Skills para Huawei, Cisco, HPE, Fortinet, Juniper, Aruba, Dell OS10, MikroTik, ESXi, Brocade FOS/ICX, iSCSI, Windows e Linux, só com comandos de consulta. Algumas avisam na descrição que ainda não foram validadas em equipamento real. Você pode ter Skills próprias em arquivos .json.

Cuidado. Execute procedimentos apenas em ambientes que você está autorizado a administrar.

6. Biblioteca novo

Clique em 🗂 Biblioteca, acima do terminal. Tudo do cliente atual fica num só lugar, com busca:

  • Sessões: cada conexão com data, duração e as evidências geradas, com os botões ▶ Assistir, 📜 Ler o log e ↻ Reconectar.
  • Gravações: só as sessões gravadas, para assistir no player.
  • Evidências: miniaturas. Clique para ampliar. Clicar no número de uma evidência dentro da sessão mostra só as daquela sessão.
  • Logs: leia o log dentro do app. A busca destaca as linhas encontradas.
  • Relatórios: os PDFs do cliente, com a indicação de assinado.
  • Skills: agrupadas por fabricante, com o botão para abrir e executar.

A Biblioteca lê as pastas do atendimento no seu computador. Nada é enviado para fora.

7. Evidências e relatório

  • Ctrl+Alt+E gera uma evidência padronizada, com número, data e fuso, equipamento e hash SHA-256.
  • Cada evidência tem um ID único e, no rodapé, chamado, técnico, origem da conexão e o SHA-256 do conteúdo.
  • No fim do atendimento, o botão 📄 Relatório monta o PDF com capa, evidências, logs originais, hashes, manifesto de custódia e a topologia (stack, LLDP, Eth-Trunk) desenhada a partir da coleta.
  • O PDF pode ser assinado no app com assinatura eletrônica (certificado próprio do técnico). Ela não é ICP-Brasil nem gov.br.
  • Os arquivos ficam no computador do técnico. A adequação a normas (ex.: ISO/IEC 27037) deve ser validada por quem audita: a confirmar caso a caso.

8. Compartilhar e assistir ao vivo

Quem compartilha

No app, inicie o compartilhamento e envie o convite (um link com código) aos participantes. Você aprova cada entrada e decide quem digita. O tráfego é cifrado de ponta a ponta (AES-256 + X25519).

Quem assiste

  1. Abra o link do convite (ele termina em #CÓDIGO) ou acesse Assistir ao vivo e digite o código.
  2. Aguarde a aprovação de quem convidou. Você entra como observador.
  3. O controle do terminal só é passado com autorização.

Também é possível entrar pelo app instalado, em 🔗 Entrar.

9. Demonstrações novo

Clique com o botão direito numa aba que não esteja conectada e escolha uma das 18 demonstrações (Sala de guerra, Mapa de ataques, Telemetria de datacenter, Falha de stack e outras).

  • É só animação: não conecta em nada, não executa comandos, não grava e não gera evidência. Os dados são fictícios.
  • Esc encerra. Qualquer tecla acelera.
  • Conectar a aba de verdade encerra a demonstração.
